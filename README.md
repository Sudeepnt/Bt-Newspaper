# BOUGHT Spotlight

The mobile newspaper and podcast prototype is a static HTML, CSS, and JavaScript site. Vercel serves the files in `public/` directly; no Next.js, vinext, or dependency installation is required.

- Newspaper: `/` or `/index.html`
- Podcast: `/podcast.html`

For local preview, run `python3 -m http.server 8000 --directory public` and open `http://localhost:8000/`.
